# Range Automation

???+ info "Next"
    Range Automation comes after Scenario Builder and Chronicle. This page describes where it's headed. Nothing here is built yet.

Range Automation takes a scenario from the Chronicle and makes it happen on a range. It will:

- **Build the environment** from the scenario's topology, through each range's own API: GraySpace, Crucible and others.
- **Run the people** by driving GHOSTS NPCs with personas, organizations and timelines taken from the Chronicle.
- **Deliver injects** on schedule, or in response to what participants do.
- **Help exercise control** steer play, with an assistant that sees the intent, the ground truth and what has happened so far.
- **Write it all back** to the Chronicle (what was built, what each NPC did, every inject), so the after-action review compares the plan with reality.

## What Exists Today

Scenario Builder's Topology page can already deploy a scenario's range to a GraySpace. See [Scenario Builder](scenario-builder/index.md#topology-and-deploy). Updraft is a read-only preview and Crucible is a stub, for now. Range Automation will build on that work.
