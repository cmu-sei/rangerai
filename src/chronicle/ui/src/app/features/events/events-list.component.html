Chronicle

Chronicle is a publish/subscribe service for Crucible events. Apps publish entries to a shared event record and subscribe to the updates they need.

During an outage drill, an exercise control app can subscribe to planned notices in Intent. When it sends a notice, it can publish the delivery to As Run. If the incoming shift says it never got the message, the team can compare the plan with the delivery record and use Lessons to document what should change at the next handover.
